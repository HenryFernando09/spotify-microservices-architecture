# Evidencias del proyecto

Esta carpeta contiene capturas de pantalla relacionadas con la implementación, dockerización y validación del microservicio Auth Service dentro del proyecto Spotify Microservices Architecture.

## Evidencias incluidas

* Construcción de la imagen Docker
* Ejecución del contenedor Docker
* Validación de endpoints mediante `curl`
* Imagen cargada en Ubuntu Server
* Validación del microservicio en máquina virtual Ubuntu Server

Las capturas permiten evidenciar el correcto funcionamiento y despliegue portable del microservicio utilizando contenedores Docker.
